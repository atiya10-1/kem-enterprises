# KEM Enterprises Catalogue Refinement

The catalogue seed is based on all supplied Jhula, Signage and Ducting catalogue pages.

- Product codes preserved: B1-B28, A1-A51, C1-C63.
- Exact printed size/finish/rate rows are stored as individual technical specification rows where the catalogue provides a table.
- "Rate as per order/need/quantity" is preserved when no fixed rate is printed.
- Missing rates (for example B21) are not invented.
- Ducting C1-C63 retain "Rate as per order" because that is what the supplied catalogue prints.
- Signage A35-A51 tables (studs, power supplies, mirror hardware, screws, LED strip, wire and chain) are stored row-by-row rather than as summary ranges.
- Jhula B1-B28 printed size/finish/rate combinations are stored row-by-row.

For an existing database created from an older seed, use a fresh production database or clear the old catalogue collections before first startup so the refined seed can populate them.
